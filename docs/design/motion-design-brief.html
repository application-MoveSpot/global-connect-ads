Keyframes — After Effects / CSS

/* ── Logomark entrance — expo-out ── */ @keyframes logoAppear { 0% { transform: scale(0.6); opacity: 0; } /* hold */ 18% { transform: scale(1.08); opacity: 1; } /* overshoot */ 28% { transform: scale(1); opacity: 1; } /* settle */ 100% { transform: scale(1); opacity: 1; } } /* ── GPS rings expansion — 3 vagues ── */ @keyframes ring1 { 0%,55% { transform: scale(0); opacity: 0; } 60% { opacity: 0.7; } 100% { transform: scale(3.5); opacity: 0; } } @keyframes ring2 { /* delay: 150ms */ } @keyframes ring3 { /* delay: 300ms */ } /* ── Tagline fade-up ── */ @keyframes taglineIn { from { opacity: 0; transform: translateY(6px); } to { opacity: 1; transform: translateY(0); } /* timing-function: cubic-bezier(0.16, 1, 0.3, 1) */ }
Note développeur. Implémenter avec Lottie (After Effects → JSON) pour garantir la fluidité sur Android.
